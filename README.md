# Dead Drop

Dead Drop is a digital time-capsule platform for storing messages and files that become available only when predefined conditions are met.

Possible unlock conditions may include:

* a specific date and time;
* approval from trusted people;
* a period of owner inactivity;
* a combination of multiple conditions.

The main idea is to allow users to securely prepare information for future delivery without giving recipients immediate access to it.
